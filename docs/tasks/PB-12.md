**User story:** As a member, I can see a dashboard with progress, overdue work, meetings, and workload.

## Files you own

`src/server/services/dashboard/**`, `src/app/api/v1/teams/[teamId]/dashboard/**`, `src/app/(app)/teams/[teamId]/page.tsx`,
`src/app/(app)/dashboard/**` (replace the foundation version), `src/components/features/dashboard/**`, tests `dashboard*`.

## Build

- `getTeamDashboard(teamId, actorId, now = new Date()): TeamDashboardDTO` — completion % (DONE / all), overdue tasks,
  due-soon (24 h), next 5 meetings (PB-06 `listMeetings`), milestones with % (read `milestone` + task counts), open
  tasks per member (not DONE; overdue count). Reads tables directly or via exported services; writes nothing.
- Route `GET /api/v1/teams/[teamId]/dashboard`.
- Team overview page (`/teams/[teamId]`): stat tiles (completion %, open, overdue, next meeting) — **graphics + text**:
  Recharts donut for completion with the number in the centre, bar chart for open tasks per member with a visually
  hidden table equivalent; overdue list (danger), due soon (warning), upcoming meetings, milestone progress bars,
  `<RecentActivity teamId limit={5} />`. Empty team → guidance ("Add tasks on the Board to see progress here").
- Personal home `/dashboard`: "My tasks" across teams (due soon first), "My next meetings", my teams grid (keep the
  existing cards), pending invites count with link.

## Acceptance criteria

- AC1: With 7 tasks of which 2 are DONE the dashboard shows 29% complete.
- AC2: Overdue = dueAt < now and not DONE; each overdue task links to the board.
- AC3: Workload shows each member's open and overdue counts, including members with 0.
- AC4: Charts have text equivalents; no serious/critical axe violations.
- AC5: Personal home lists only my assigned, not-DONE tasks across my teams.

## Required tests

Integration for `getTeamDashboard` with fixed `now` (AC1–AC3, AC5); E2E: open the seeded team overview, check tiles; a11y.
