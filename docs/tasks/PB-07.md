**User story:** As a member, I can share notes, links, and file references with my team.

## Contracts

`src/contracts/resources.ts` (`createResourceInput` discriminated by `type`, `updateResourceInput`,
`listResourcesQuery`, `ResourceDTO`), `api.md` § PB-07. Table `resource`. **No uploads** (out of scope) — FILE_REF is a
link to Google Drive / OneDrive / Canvas.

## Build

**Service** `src/server/services/resources/service.ts`: `listResources(teamId, actorId, {type, q})` (pinned first, then
newest; `q` searches title + body, case-insensitive), `createResource` (`RESOURCE_ADDED`, summary "added the link “X”"),
`updateResource` (any member may toggle `pinned`; other fields creator or leader → 403 otherwise; `RESOURCE_UPDATED`),
`deleteResource` (creator or leader; `RESOURCE_DELETED`). Changing `url` on a NOTE or `body` on a LINK → 400.
Pure `source.ts`: `detectSource(url)` → `"Google Drive" | "OneDrive" | "Canvas" | "GitHub" | "Web"` from the hostname (unit-tested).

**Routes** exactly as `api.md` § PB-07 (`teamRoute`).

**Page** `/teams/[teamId]/resources` (`SectionHeader` "Resources", action **Add**)
- Filter chips All / Notes / Links / Files, search box (debounced, updates `?q=`).
- List rows: type icon (lucide `StickyNote`, `Link`, `FileText`) + title + source badge (`detectSource`) + creator + relative
  time; pinned section on top with a pin toggle button (`aria-pressed`).
- Links/files open in a new tab with `rel="noopener noreferrer"` and an external-link icon + accessible label.
- Notes expand inline (progressive disclosure) with preserved line breaks.
- Add/edit `Dialog`: type selector (segmented) → fields for that type; URL hint "Paste a share link from Google Drive,
  OneDrive, or Canvas". Delete with `ConfirmDialog`.
- Empty state: "Share the syllabus, your Drive folder, or meeting notes."

## Acceptance criteria

- AC1: A member adds a link, a file reference, and a note; they appear newest first and activity records each.
- AC2: A pinned item appears above unpinned ones for everyone.
- AC3: `ftp://` or `javascript:` URLs are rejected with a clear message.
- AC4: Only the creator or a leader can edit or delete (403 for others); any member can pin.
- AC5: Search finds a note by a word in its body; filters by type.
- AC6: Non-members get 403 (sweep); no serious/critical axe violations.

## Required tests

- Unit `tests/unit/resources-source.test.ts`: `detectSource`.
- Integration `tests/integration/resources.test.ts`: AC1–AC5 with activity assertions.
- E2E `cypress/e2e/resources.cy.ts`: add a link, pin it, search, delete; a11y.
