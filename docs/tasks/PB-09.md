## Build

**Service** `src/server/services/activity/service.ts` — ★ `listActivity(teamId, actorId, query): Promise<Page<ActivityDTO>>`:
membership check, newest first by `(createdAt desc, id desc)`, keyset cursor, filters `type`, `entityType`, `actorId`.
Pure `format.ts`: `activitySentence(dto)` → "Krish moved “Slides” to Review" (actor name + summary; "Someone" when
actor deleted) and `groupByDay(items, timeZone, now)` → `[{ label: "Today" | "Yesterday" | "Mon, Oct 19", items }]`.

**Route** `GET /api/v1/teams/[teamId]/activity` (`teamRoute`).

**Page** `/teams/[teamId]/activity` (`SectionHeader` "Activity")
- Filters: member select, category select (Tasks, Meetings, Resources, Team, AI, Milestones, Polls → `entityType`), kept in
  the URL (`?actor=&entity=`).
- Timeline grouped by day (`groupByDay` in viewer tz): avatar, sentence, small type icon, relative time with
  `<time dateTime>` + absolute title.
- **Load more** button (cursor). Empty state: "No activity yet — create a task or schedule a meeting."
- `RecentActivity` server component: last `limit` events as a compact list + "View all" link.

## Acceptance criteria

- AC1: Team actions appear newest first with who did what and when, in my timezone.
- AC2: Filtering by member and by category shows only matching events; the filter survives reload (URL).
- AC3: Load more returns the next page without duplicates or gaps.
- AC4: A non-member gets 403 (sweep) and can't see events.
- AC5: Events whose actor was deleted show "Someone".
- AC6: No serious/critical axe violations.
