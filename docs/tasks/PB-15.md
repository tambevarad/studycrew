**User story:** As a member, I can add agenda items and flag topics I need help with before a meeting.

## Files you own

`src/server/services/agenda/**`, `src/app/api/v1/teams/[teamId]/meetings/[meetingId]/agenda/**`,
`src/components/features/agenda/**` (**keep** `export function MeetingAgenda({ teamId, meetingId })` — may become async),
tests `agenda*`.

## Build

- Service: `listAgenda(teamId, actorId, meetingId)` sorted by `helpCount` desc then `createdAt`; `addAgendaItem`
  (`AGENDA_ITEM_ADDED`); `setHelpFlag(itemId, { needsHelp })` (idempotent per member); `deleteAgendaItem` (author or leader).
  Meeting must belong to the team (404).
- UI on the meeting page: "Agenda" card, add-topic input, each item shows title, notes, author, "🙋 3 need help" count
  with a toggle button "I need help with this" (`aria-pressed`), sorted live. Empty: "Add topics so everyone comes prepared."

## Acceptance criteria

- AC1: Items are sorted by how many members flagged them.
- AC2: A member can flag/unflag once; counts update.
- AC3: Only author or leader can delete; meeting from another team → 404.

## Required tests

Integration for routes (AC1–AC3); E2E on the seeded meeting.
